# RepFolio – notes for Claude

Personal iOS gym & running tracker. SwiftUI + SwiftData + Swift Charts, iOS 17+, Xcode 16+ (folder-synced project: new files under `RepFolio/` are added to the target automatically – don't edit `project.pbxproj` for that).

## Conventions
- UI text is **German** or **English** (switchable), code/comments/README are **English**.
- Swift language mode 5. No third-party dependencies.
- Data model lives in `RepFolio/Models/Models.swift`. When you add or change a stored property, also update `BackupService` (export + restore) so backups stay complete.
  Prefer additive changes with default values (lightweight migration); never rename the store or the bundle id – users would lose data.
- Exercise catalog: `RepFolio/Resources/exercises.json`, generated by `Scripts/curate_exercises.py` from Free Exercise DB (public domain). Image names: `<id>_<n>.jpg`.
- Chart colors: `Color.chartGym` / `.chartRun` / `.chartBase` (fixed identity, light/dark variants).
- Localization: `RepFolio/Resources/Localizable.xcstrings` (source language German). Command-line builds don't sync the catalog – when you add or change UI strings, add the keys with their English translation yourself (interpolations become `%@` / `%lld`, use positional `%1$@` when the order changes).

## Signing
Team ID and bundle id prefix come from the git-ignored `Config/Signing.xcconfig` (via `Base.xcconfig`). Never touch the Team dropdown in Xcode's Signing & Capabilities – picking a team *or* "None" writes `DEVELOPMENT_TEAM` into `project.pbxproj`, which overrides the xcconfig (and would leak the Team ID).

## Privacy (public repo)
Never commit on your own! The commit and push is up to the developer! But always check that no personal data or signing info: `Config/Signing.xcconfig`, backups (`RepFolio-*.json`, older `IronLog-*.json`), CSV exports, `*.store`/`*.sqlite`, or a `DEVELOPMENT_TEAM` value in `project.pbxproj`. `Scripts/check-private.sh` is inside the commit scope. Check this before finishing the code.
